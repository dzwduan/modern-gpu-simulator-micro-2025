# 第 9 章：源码锚点索引

---

## 术语说明

| 术语 | 说明 |
|---|---|
| SM | Streaming Multiprocessor，GPU 流处理器，顶层调度单元 |
| Subcore | SM 内的子核心，每个 Subcore 拥有独立的 8 级流水线和 RF |
| FU | Functional Unit，功能单元，执行算术/访存/特殊操作 |
| IBuffer | Instruction Buffer，指令缓冲区，per-warp 的 FIFO 队列 |
| RF | Register File，寄存器文件，分 regular 和 uniform 两种 |
| PRT | Pending Request Table，访存请求跟踪表 |
| Dependency_State | Per-warp 依赖状态对象，管理 wait barrier / yield / stall counter |
| Scoreboard | 记分板，用于传统 RAW/WAW 冒险检测 |
| Scoreboard_reads | 读记分板，用于 WAR 冒险检测 |
| register_set_uniptr | 流水线级间寄存器容器，持有 `vector<unique_ptr<warp_inst_t>>` |
| warp_inst_t | Warp 级指令对象，携带 PC、操作码、操作数、control bits 等全部信息 |

### SM 关键函数签名

```cpp
// SM 每周期主循环：驱动 L0_icnt、L1I、shared DP unit、ldst_unit_sm、所有 subcore，
// 最后消费 pending barrier actions
void SM::cycle();

// 指令退休：释放 scoreboard/write barrier，decrement inst_in_pipeline，
// 调用 warp_inst_complete()
// @param instruction  待退休的指令指针
void SM::instruction_retirement(warp_inst_t *instruction);

// 消费 pending barrier stack（LIFO 顺序）
// @param actions  std::stack<Wait_Barrier_Entry_Modifier>& 引用
void SM::consume_pending_wait_barrier_actions(std::stack<Wait_Barrier_Entry_Modifier> &actions);

// 添加 barrier decrement 到 pending stack
// @param inst          触发 decrement 的指令
// @param barrier_type  READ_WAIT_BARRIER 或 WRITE_WAIT_BARRIER
// @param barrier_id    barrier 编号 [0, num_wait_barriers_per_warp)
void SM::add_pending_wait_barrier_decrement(warp_inst_t *inst, Wait_Barrier_Type barrier_type, unsigned int barrier_id);

// 添加 barrier increment 到 pending stack
// @param inst          触发 increment 的指令
// @param barrier_type  READ_WAIT_BARRIER 或 WRITE_WAIT_BARRIER
// @param barrier_id    barrier 编号 [0, num_wait_barriers_per_warp)
void SM::add_pending_wait_barrier_increment(warp_inst_t *inst, Wait_Barrier_Type barrier_type, unsigned int barrier_id);

// 发射指令：移入 pipe_reg_set，调用 IBuffer::issued()，执行 func_exec_inst()
// @param pipe_reg_set               目标 latch（m_ISSUE_CONTROL_latch）
// @param next_inst                  待发射指令
// @param active_mask                活跃线程掩码
// @param warp_id                    SM 级 warp ID
// @param subcore_id                 Subcore 编号
// @param use_traditional_scoreboarding  是否使用传统记分板模式
void SM::issue_warp(register_set_uniptr &pipe_reg_set, warp_inst_t *next_inst,
                    const active_mask_t &active_mask, unsigned warp_id,
                    unsigned subcore_id, bool use_traditional_scoreboarding);
```

### Subcore 关键函数签名

```cpp
// Subcore 每周期主循环：逆序调用 writeback→execute→read_rf→allocate→control_stage→issue→decode→fetch
void Subcore::cycle();

// Fetch 阶段：从 L0I 取响应填入 fetch-decode latch；按 greedy 顺序为 warp 发起 L0I 请求
// @param shared_sm  SM 指针，用于获取配置和全局 PC 转换
void Subcore::fetch(SM *shared_sm);

// Decode 阶段：从 fetch-decode latch 取 PC，调用 get_next_inst() 获取 trace 指令，
// 通过 single_decode() 填充 IBuffer entry
// @param shared_sm  SM 指针
void Subcore::decode(SM *shared_sm);

// Issue 阶段：Greedy-then-highest-id 调度，检查所有就绪条件后发射指令
// @param shared_sm  SM 指针
void Subcore::issue(SM *shared_sm);

// Control 阶段：设置 barrier increment；fixed latency 指令移入 CONTROL_ALLOCATE_latch，
// variable latency 指令直接 issue 到 FU
// @param shared_sm  SM 指针
void Subcore::control_stage(SM *shared_sm);

// Allocate 阶段：检查 RF 读端口和 FU latency 槽位，成功则预留资源
// @param shared_sm  SM 指针
void Subcore::allocate(SM *shared_sm);

// Read RF 阶段：3/6 级移位寄存器推进，最后一级调用 release_read_barrier() + fu->issue()
// @param shared_sm  SM 指针
void Subcore::read_rf(SM *shared_sm);

// Execute 阶段：驱动所有 subcore 内 FU 的 cycle()
void Subcore::execute();

// Writeback 阶段：处理 regular/uniform 固定延迟结果队列 + variable latency latch + SM 共享单元 latch
// @param shared_sm  SM 指针
void Subcore::writeback(SM *shared_sm);

// 发射执行：设置 FU、管理操作数统计、调用 SM::issue_warp()、预留结果队列槽位
// @param shared_sm              SM 指针
// @param dispatch_latch         目标 latch
// @param pI                     待发射指令
// @param active_mask            活跃线程掩码
// @param sm_warp_id             SM 级 warp ID
// @param fu                     目标 FU
// @param is_fixed_latency_inst  是否固定延迟指令
// @param use_traditional_scoreboarding  是否使用传统记分板
// @param has_dst_reg            是否有目标寄存器
// @param dst_result_queue_type  目标结果队列类型（REG/UREG）
void Subcore::issue_warp(SM *shared_sm, register_set_uniptr &dispatch_latch, warp_inst_t *pI,
                         const active_mask_t &active_mask, unsigned sm_warp_id,
                         functional_unit* fu, bool is_fixed_latency_inst,
                         bool use_traditional_scoreboarding,
                         bool has_dst_reg, TraceEnhancedOperandType dst_result_queue_type);

// Barrier 就绪检查入口：根据指令类型分发到 generic 或 depbar 检查
// @param inst              待检查指令
// @param subcore_warp_id   Subcore 内 warp ID
// @return                  所有 barrier 是否就绪
bool Subcore::is_wait_barriers_ready_entry_point(const warp_inst_t* inst, unsigned int subcore_warp_id);

// FU 选择：根据指令 op 类型返回对应的 functional_unit 指针
// @param pI  指令指针
// @return    对应的 FU 指针（SP/INT/DP/UNIFORM/TENSOR/BRANCH/SFU/MISC/MEM）
functional_unit* Subcore::get_fu(const warp_inst_t *pI);
```

// @param result_port       结果输出端口（latch）
// @param regular_rf        Regular RF 指针（用于 variable latency RF 读）
// @param config            配置
// @param max_latency       最大延迟（决定 m_pipeline_depth）
// @param name              FU 名称（"SP"/"INT"/"MEM_SUBCORE_UNIT" 等）

                                 bool can_set_wait_barriers, bool has_queue,
                                 unsigned int max_queue_size,
                                 unsigned int num_intermediate_cycles_until_fu_execution,
                                 register_set_uniptr *fixed_latency_rf_write_queue,
                                 unsigned int max_size_rf_write_queue,
                                 bool has_to_go_to_shared_sm_structure,
                                 TraceEnhancedOperandType result_queue_type);

## 关键调用关系

### SM::cycle() 主调用链

```
SM::cycle()
├── Phase 1: L0_icnt::cycle()                          // L0<->L1 互连推进（m_icnt_L0s）
├── Phase 2: m_L1I_L1_half_C_cache->cycle()             // L1I / half-constant cache 推进
├── Phase 3: m_shared_dp_unit->cycle()                  // 共享 DP 单元推进（is_dp_pipeline_shared_for_subcores 时）
├── Phase 4: m_ldst_unit_shared_of_sm->cycle()          // 共享访存单元推进
│            ├── writeback()                           // 写回仲裁
│            ├── cache_cycles()                        // L1D/L1C/L1T/SHMEM 推进
│            ├── management_entries_to_process()        // PRT 选择
│            └── issue()                               // 输入仲裁 + PRT 分配
├── Phase 5: 对每个 subcore 调用 Subcore::cycle()         // 各 Subcore 流水线（逆序）+ 私有 L0I/L0C 推进
│            ├── writeback()
│            │   └── writeback_process_fixed_latency_write_queue()
│            │   └── writeback_latch_proccess()
│            │       └── SM::instruction_retirement()
│            ├── execute()
│            │   └── functional_unit::cycle()
│            ├── read_rf()
│            │   └── functional_unit::release_read_barrier()
│            │   └── functional_unit::issue()
│            │   └── Register_file::cycle()
│            ├── allocate()
│            │   └── Register_file::is_possible_to_read_cacheable()
│            │   └── functional_unit::reserve_latency()
│            ├── control_stage()
│            │   └── SM::add_pending_wait_barrier_increment()
│            ├── issue()
│            │   └── modify_warp_state()
│            │       └── Dependency_State::cycle()
│            │   └── order_greedy_then_highest_id()
│            │   └── is_wait_barriers_ready_entry_point()
│            │   └── issue_warp()
│            │       └── SM::issue_warp()
│            │           └── Dependency_State::set_stall_counter()
│            │           └── Dependency_State::set_yield()
│            ├── decode()
│            └── fetch()
│                └── IBuffer_Remodeled::fill()
├── Phase 6: consume_pending_wait_barrier_actions(increments)
├── Phase 7: consume_pending_wait_barrier_actions(decrements)
│            └── Dependency_State::action_over_wait_barrier()
└── Phase 8: m_num_cycles_to_wait_to_dispatch--
```

### 访存指令跨模块调用链

```
Subcore::issue() → issue_warp() → SM::issue_warp()
  → Subcore::control_stage() → 指令进入 m_CONTROL_ALLOCATE_latch（固定延迟）
                              → functional_unit::issue()（可变延迟 MEM/DP）
    → functional_unit_subcore_to_sm_shared_part::issue()
      → 指令写入 m_EX_MEM_reception_latches_per_subcore[subcore_id]
        → ldst_unit_sm::cycle() 步骤 8: 输入仲裁
          → ldst_unit_sm::issue() → PRT::assign_entry()
            → PRT::management_entries_to_process() → 生成 access
              → InterWarpCoalescingUnit::insert_access() / pop_access()
                → 路由到子流水线 (L1D/SHMEM/L1C/L1T/Bypass)
                  → pending_access_logic() → PRT::solve_access()
                    → ldst_unit_sm::writeback() → PRT::pop_entry()
                      → m_result_ports[subcore_id] → Subcore::writeback()
                        → SM::instruction_retirement()
```
