# 第 8 章：配置矩阵

---

## 8.0 术语说明

| 缩写/术语 | 全称 | 说明 |
|---|---|---|
| SM | Streaming Multiprocessor | 流多处理器，GPU 核心计算单元 |
| Subcore | Sub-core Partition | SM 内的子核分区，每个拥有独立调度器、RF、FU |
| RF | Register File | 寄存器文件，banked 结构 |
| RF Cache | Register File Cache | 寄存器文件缓存，按 operand position x bank 组织 |
| FU | Functional Unit | 功能单元 |
| SP | Single Precision | 单精度浮点流水线 |
| DP | Double Precision | 双精度浮点流水线（SM 级共享） |
| SFU | Special Function Unit | 特殊函数单元（sin/cos/sqrt/log 等） |
| INT | Integer Pipeline | 整数流水线（unified 模式下合并到 SP） |
| MEM | Memory Pipeline | 访存流水线 |
| PRT | Pending Request Table | 待处理请求表 |
| IBuffer | Instruction Buffer | 指令缓冲区（per-warp） |
| L0I | Level-0 Instruction Cache | Subcore 私有零级指令缓存 |
| L1I | Level-1 Instruction Cache | SM 级共享一级指令缓存 |
| L1D | Level-1 Data Cache | SM 级共享一级数据缓存 |
| L1C | Level-1 Constant Cache | SM 级共享一级常量缓存 |
| L1T | Level-1 Texture Cache | SM 级共享一级纹理缓存 |
| SMEM | Shared Memory | 共享内存 |
| LDGSTS | Load Global Store Shared | 异步全局→共享内存拷贝指令 |
| InterWarp Coalescing | Inter-Warp Memory Coalescing | 跨 warp 访存合并 |
| LOOG | Load Operand Ordering Graph | 操作数排序图 |
| VPREG | Virtual Physical Register | 虚拟物理寄存器映射 |
| True-Path | True Execution Path | 本文档定义的唯一有效执行路径 |

## 8.0B 设计规格

配置系统的整体能力规格：

| 规格项 | 值 | 说明 |
|---|---|---|
| True-Path 固定配置参数 | 13 个 | 布尔类型，决定执行路径选择 |
| 可调配置参数类别 | 7 类 | SM 级、Subcore 级、FU 延迟、共享访存、L0/L1 互连、SM 共享调度、InterWarp Coalescing |
| 可调配置参数总数 | 40+ 个 | 涵盖结构规模、延迟、队列深度、调度策略 |
| 配置文件格式 | `-key value` 文本格式 | 由 `gpu-sim-config.cc` 解析注册 |
| 已验证 GPU 配置 | SM75 (RTX 2070S/2080Ti)、SM86 (RTX 3080/3090/A6000)、SM89 (RTX 4090)、SM120 (RTX 5070Ti) | `configs/tested-cfgs/` 目录 |
| 参数存储类 | `shader_core_config` | 定义于 `shader.h`，包含所有配置参数声明 |

## 8.1 True-Path 固定配置

本文档所有描述均基于以下配置矩阵。这些参数在 True-Path 下取固定值，文档中不描述其他取值下的行为。

| 参数 | 固定值 | 类型 | 有效范围 | 文中语义 | 影响模块 |
|---|---:|---|---|---|---|
| `is_trace_mode` | `true` | `bool` | true/false | 指令来源于 trace；dependency 走 control-bit 逻辑 | SM、Subcore（指令获取路径） |
| `is_captured_from_binary` | `true` | `bool` | true/false | 配合 trace，使 control-bit 路径成立 | Subcore control_stage |
| `is_SM_remodeling_enabled` | `true` | `bool` | true/false | 运行入口选择 `SM`（而非 legacy shader core） | 顶层调度入口 |
| `is_remodeling_scoreboarding_enabled` | `false` | `bool` | true/false | 禁用传统 remodeling scoreboard 路径 | Subcore issue、SM retire |
| `is_ibuffer_remodeled_enabled` | `true` | `bool` | true/false | 采用 `IBuffer_Remodeled` 主路径 | Subcore fetch/decode/issue |
| `is_interwarp_coalescing_enabled` | `true` | `bool` | true/false | 启用跨 warp 合并逻辑 | ldst_unit_sm |
| `is_instruction_prefetching_enabled` | `true` | `bool` | true/false | 启用 L0I stream buffer 预取 | first_level_instruction_cache |
| `is_fp32_and_int_unified_pipeline` | `true` | `bool` | true/false | INT/PREDICATE 与 SP 共享发射资源 | Subcore issue（FU 选择） |
| `is_fp32ops_allowed_in_int_pipeline` | `true` | `bool` | true/false | 仅在存在独立 INT pipeline 时有效；unified 模式下应视为无效配置位 | Subcore issue |
| `is_dp_pipeline_shared_for_subcores` | `true` | `bool` | true/false | DP 走 subcore→SM shared DP 路径 | Subcore m_dp_pipeline、SM m_shared_dp_unit |
| `is_rf_cache_enabled` | `true` | `bool` | true/false | regular RF 使用 cacheable 读路径 | Register_file |
| `is_loog_enabled` | `true` | `bool` | true/false | pending write 首键使用 `m_cu_rrs_id` | ldst_unit_sm |
| `is_vpreg_enabled` | `true` | `bool` | true/false | pending write 次键使用 `vpreg_virtual_out` | ldst_unit_sm |

## 8.2 可调配置参数

以下参数在 True-Path 下不固定，由具体硬件配置决定：

### SM 级参数

| 参数 | 类型 | 说明 | SM86 A6000 典型值 | 有效范围 | 影响模块 |
|---|---|---|---:|---|---|
| `num_subcores` | `unsigned int` | Subcore 数量 | 4 | 1~8 | SM（`m_subcores` 数组大小）、warp 映射（`warp_id % num_subcores`） |
| `max_warps_per_shader` | `unsigned int` | SM 内最大 warp 数（`n_thread_per_shader / warp_size`） | 48 | 1~`MAX_THREAD_PER_SM/32`=128 | SM（`m_physical_warp` 数组大小）、Subcore（per-subcore warp 数） |
| `max_cta_per_core` | `unsigned int` | SM 内最大 CTA 数 | 32 | 1~`MAX_CTA_PER_SHADER`=32 | SM（CTA 调度、`m_cta_status` 数组） |

### Subcore 级参数

| 参数 | 类型 | 说明 | SM86 A6000 典型值 | 有效范围 | 影响模块 |
|---|---|---|---:|---|---|
| `ibuffer_remodeled_size` | `int` | IBuffer 深度（per warp） | 3 | >=1 | IBuffer_Remodeled（`m_num_max_entries`） |
| `fetch_decode_width` | `int` | 每次 fetch/decode 的指令数 | 1 | >=1 | IBuffer_Remodeled（`m_fetch_decode_width`，`can_fetch()` 判定） |
| `gpgpu_num_reg_banks` | `unsigned int` | RF bank 总数（各 subcore 均分） | 8 | 2~32（需被 num_subcores 整除） | Register_file（`m_num_banks`），每 subcore 分得 `8/4=2` banks |
| `num_regular_register_file_read_ports_per_bank` | `int` | regular RF 每 bank 读端口数 | 1 | 1~99 | Register_file_bank（`m_num_read_ports`） |
| `num_regular_register_file_write_ports_per_bank` | `int` | regular RF 每 bank 写端口数 | 1 | 1~99 | Register_file_bank（`m_num_write_ports`） |
| `max_latency_regular_register_file_latency` | `int` | RF 最大支持延迟（bank 端口预约窗口深度） | 24 | >=1 | Register_file_bank（`m_num_used_read/write_ports` 向量长度） |
| `max_operands_regular_register_file` | `int` | RF cache 最大操作数位置数 | 4 | 1~`MAX_REG_OPERANDS`=32 | Register_file_cache（`m_max_num_operands`，第一维大小） |
| `max_size_register_file_write_queue_for_fixed_latency_instructions` | `int` | 固定延迟结果队列深度 | 8 | >=1 | Subcore（`m_regular_fixed_latency_rf_write_queue` 容量） |
| `max_pops_per_cycle_register_file_write_queue_for_fixed_latency_instructions` | `int` | 每周期结果队列弹出数 | 1 | >=1 | Subcore writeback（每周期最大写回数） |

### FU 延迟参数

| 参数 | 类型 | 说明 | SM86 A6000 典型值 | 有效范围 | 影响模块 |
|---|---|---|---:|---|---|
| `max_sp_latency` | `unsigned int` | SP pipeline depth | 4（由 `ptx_opcode_latency_fp` 决定） | >=1 | functional_unit（SP pipeline 深度） |
| `max_int_latency` | `unsigned int` | INT pipeline depth（unified 下不使用） | 4（由 `ptx_opcode_latency_int` 决定） | >=1 | functional_unit（INT pipeline 深度） |
| `max_dp_latency` | `unsigned int` | DP pipeline depth | 64（由 `ptx_opcode_latency_dp` 决定） | >=1 | functional_unit（DP pipeline 深度） |
| `uniform_latency` | `int` | Uniform pipeline depth | 2 | >=1 | functional_unit（Uniform pipeline） |
| `tensor_latency` | `int` | Tensor Core pipeline depth | 32 | >=1 | functional_unit（Tensor pipeline） |
| `branch_latency` | `int` | Branch pipeline depth | 2 | >=1 | functional_unit（Branch pipeline） |
| `sfu_latency` | `int` | SFU pipeline depth | 21（由 `ptx_opcode_latency_sfu` 决定） | >=1 | functional_unit（SFU pipeline） |
| `miscellaneous_queue_latency` | `int` | MISC_QUEUE pipeline depth | 2 | >=1 | functional_unit（MISC_QUEUE pipeline） |
| `miscellaneous_queue_size` | `unsigned int` | MISC_QUEUE 队列深度 | 3 | >=1 | functional_unit（MISC_QUEUE 内部队列容量） |
| `miscellaneous_no_queue_latency` | `int` | MISC_NO_QUEUE pipeline depth | 1 | >=1 | functional_unit（MISC_NO_QUEUE pipeline） |
| `memory_subcore_queue_size` | `unsigned int` | MEM subcore 队列深度 | 4 | >=1 | functional_unit（MEM subcore 内部队列容量） |
| `memory_intermidiate_stages_subcore_unit` | `unsigned int` | MEM 中间级数 | 6 | >=0 | functional_unit（MEM subcore 中间流水线级数） |
| `dp_subcore_queue_size` | `unsigned int` | DP subcore 队列深度 | 3 | >=1 | functional_unit（DP subcore 内部队列容量） |
| `dp_subcore_max_latency` | `unsigned int` | DP subcore pipeline depth | 13 | >=1 | functional_unit（DP subcore pipeline 深度） |
| `dp_shared_intermidiate_stages` | `unsigned int` | DP 共享中间级数 | 6 | >=0 | SM m_shared_dp_unit（共享 DP 中间流水线级数） |

| 参数 | 类型 | 说明 | SM86 A6000 典型值 | 有效范围 | 影响模块 |

## 8.3 参数依赖关系

以下参数之间存在约束或联动关系：

| 约束 | 参数 A | 参数 B | 关系 | 说明 |
|---|---|---|---|---|
| 1 | `gpgpu_num_reg_banks` | `num_subcores` | A 需被 B 整除 | 每 subcore 分得 `A/B` 个 bank |
| 2 | `max_warps_per_shader` | `num_subcores` | A / B = per-subcore warp 数 | warp 按 `warp_id % num_subcores` 映射 |
| 3 | `is_fp32_and_int_unified_pipeline` | `is_fp32ops_allowed_in_int_pipeline` | A=true 时 B 无效 | unified 模式下 INT 合并到 SP |
| 4 | `is_trace_mode` | `is_captured_from_binary` | 两者需同时为 true | control-bit 路径成立条件 |
| 5 | `is_SM_remodeling_enabled` | `is_ibuffer_remodeled_enabled` | 两者需同时为 true | True-Path 主路径 |
| 6 | `maximum_l1d_latency_at_sm_structure` | `memory_l1d_minimum_latency` | A 由 B 决定 | L1D latency queue 深度 |
| 7 | `maximum_shared_memory_latency_at_sm_structure` | `memory_shared_memory_minimum_latency` | A 由 B 决定 | SHMEM 流水线深度 |
| 8 | `is_dp_pipeline_shared_for_subcores` | `dp_subcore_*` / `dp_shared_*` | A=true 时使用 shared 参数 | DP 走 SM 级共享路径 |
| 9 | `is_interwarp_coalescing_enabled` | `num_interwarp_coalescing_tables` / `max_size_interwarp_coalescing_per_table` | A=false 时 B 无效 | 合并功能开关 |
| 10 | `is_rf_cache_enabled` | `max_operands_regular_register_file` | A=false 时 B 无效 | RF cache 功能开关 |
