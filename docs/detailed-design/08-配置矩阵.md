# 第 8 章：配置矩阵

---

## 8.1 True-Path 固定配置

本文档所有描述均基于以下配置矩阵。这些参数在 True-Path 下取固定值，文档中不描述其他取值下的行为。

| 参数 | 固定值 | 文中语义 |
|---|---:|---|
| `is_trace_mode` | `true` | 指令来源于 trace；dependency 走 control-bit 逻辑 |
| `is_captured_from_binary` | `true` | 配合 trace，使 control-bit 路径成立 |
| `is_SM_remodeling_enabled` | `true` | 运行入口选择 `SM`（而非 legacy shader core） |
| `is_remodeling_scoreboarding_enabled` | `false` | 禁用传统 remodeling scoreboard 路径 |
| `is_ibuffer_remodeled_enabled` | `true` | 采用 `IBuffer_Remodeled` 主路径 |
| `is_interwarp_coalescing_enabled` | `true` | 启用跨 warp 合并逻辑 |
| `is_instruction_prefetching_enabled` | `true` | 启用 L0I stream buffer 预取 |
| `is_fp32_and_int_unified_pipeline` | `true` | INT/PREDICATE 与 SP 共享发射资源 |
| `is_fp32ops_allowed_in_int_pipeline` | `true` | 仅在存在独立 INT pipeline 时有效；unified 模式下应视为无效配置位 |
| `is_dp_pipeline_shared_for_subcores` | `true` | DP 走 subcore→SM shared DP 路径 |
| `is_rf_cache_enabled` | `true` | regular RF 使用 cacheable 读路径 |
| `is_loog_enabled` | `true` | pending write 首键使用 `m_cu_rrs_id` |
| `is_vpreg_enabled` | `true` | pending write 次键使用 `vpreg_virtual_out` |

## 8.2 可调配置参数

以下参数在 True-Path 下不固定，由具体硬件配置决定：

### SM 级参数

| 参数 | 说明 | 典型值 |
|---|---|---|
| `num_subcores` | Subcore 数量 | 4 |
| `max_warps_per_shader` | SM 内最大 warp 数 | 48/64 |
| `max_cta_per_core` | SM 内最大 CTA 数 | 16/32 |

### Subcore 级参数

| 参数 | 说明 |
|---|---|
| `ibuffer_remodeled_size` | IBuffer 深度（per warp） |
| `fetch_decode_width` | 每次 fetch/decode 的指令数 |
| `gpgpu_num_reg_banks` | RF bank 总数（各 subcore 均分） |
| `num_regular_register_file_read_ports_per_bank` | regular RF 每 bank 读端口数 |
| `num_regular_register_file_write_ports_per_bank` | regular RF 每 bank 写端口数 |
| `max_latency_regular_register_file_latency` | RF 最大支持延迟 |
| `max_operands_regular_register_file` | RF cache 最大操作数位置数 |
| `max_size_register_file_write_queue_for_fixed_latency_instructions` | 固定延迟结果队列深度 |
| `max_pops_per_cycle_register_file_write_queue_for_fixed_latency_instructions` | 每周期结果队列弹出数 |

### FU 延迟参数

| 参数 | 说明 |
|---|---|
| `max_sp_latency` | SP pipeline depth |
| `max_int_latency` | INT pipeline depth（unified 下不使用） |
| `max_dp_latency` | DP pipeline depth |
| `uniform_latency` | Uniform pipeline depth |
| `tensor_latency` | Tensor Core pipeline depth |
| `branch_latency` | Branch pipeline depth |
| `sfu_latency` | SFU pipeline depth |
| `miscellaneous_queue_latency` | MISC_QUEUE pipeline depth |
| `miscellaneous_queue_size` | MISC_QUEUE 队列深度 |
| `miscellaneous_no_queue_latency` | MISC_NO_QUEUE pipeline depth |
| `memory_subcore_queue_size` | MEM subcore 队列深度 |
| `memory_intermidiate_stages_subcore_unit` | MEM 中间级数 |
| `dp_subcore_queue_size` | DP subcore 队列深度 |
| `dp_subcore_max_latency` | DP subcore pipeline depth |
| `dp_shared_intermidiate_stages` | DP 共享中间级数 |

### 共享访存单元参数

| 参数 | 说明 |
|---|---|
| `memory_sm_prt_size` | PRT 最大 entry 数 |
| `sm_memory_unit_l1d_access_queue_size` | L1D 队列深度（per bank） |
| `sm_memory_unit_l1c_access_queue_size` | L1C 队列深度 |
| `sm_memory_unit_l1t_access_queue_size` | L1T 队列深度 |
| `sm_memory_unit_shmem_access_queue_size` | 共享内存队列深度 |
| `sm_memory_unit_bypass_l1d_directly_go_to_l2_access_queue_size` | Bypass 队列深度 |
| `m_L1D_config.l1_banks` | L1D bank 数 |
| `maximum_l1d_latency_at_sm_structure` | L1D latency queue 深度 |
| `maximum_shared_memory_latency_at_sm_structure` | 共享内存流水线深度 |
| `memory_l1d_max_lookups_per_cycle_per_bank` | 每 bank 每周期最大 L1D 查找数 |
| `num_interwarp_coalescing_tables` | InterWarp Coalescing 表数量 |
| `max_size_interwarp_coalescing_per_table` | 每表最大 entry 数 |

### L0/L1 互连参数

| 参数 | 说明 |
|---|---|
| `max_request_allowed_to_L1I` | L0→L1 最大在途请求数 |
| `max_reply_allowed_from_L1I` | L1→L0 最大在途响应数 |
| `latency_L0_to_L1` | 请求方向延迟 |
| `latency_L1_to_L0` | 响应方向延迟 |

### SM 共享单元调度间隔

| 参数 | 说明 |
|---|---|
| `num_cycles_to_wait_to_dispatch_another_inst_from_subcore_to_sm_shared_pipeline_when_is_mem_inst` | MEM 指令调度间隔 |
| `num_cycles_to_wait_to_dispatch_another_inst_from_subcore_to_sm_shared_pipeline_when_is_dp_inst` | DP 指令调度间隔 |
